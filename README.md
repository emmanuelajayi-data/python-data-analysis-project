# 🐍 Python Data Analysis & Visualization Project

An exploratory data analysis and visual reporting project built using Python, leveraging core data science libraries within an interactive Google Colab environment.

## 📊 Project Overview
This repository showcases programmatic data manipulation, handling datasets, and building clean data visualizations to extract actionable insights from raw data.

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib
- **Environment:** Google Colab / Jupyter Notebook

## 🔍 Key Visualizations & Analysis
1. **City Temperature Analysis:** Plotted and compared daily high temperatures across key Nigerian cities using line charts.
2. **Regional Revenue Breakdown:** Bar chart comparing total sales performance across regions (North America, Europe, Asia Pacific, and Latin America).
3. **Product Category Distribution:** Pie chart illustrating revenue shares across different product categories (Furniture, Office Supplies, Electronics).
4. **Customer Satisfaction Mapping:** Histogram mapping user feedback scores on a 1–5 scale.
5. **Temporal Revenue Trends:** Time-series line chart tracking daily revenue fluctuations over time.

## 🚀 How to Run
1. Open the `.ipynb` file directly in Jupyter Notebook or Google Colab.
2. Ensure required dependencies (`pandas`, `matplotlib`, `numpy`) are installed.
3. Run cells sequentially to reproduce the data cleaning and visual plots.
